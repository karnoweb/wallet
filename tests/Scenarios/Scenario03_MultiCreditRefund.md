# سناریو ۰۳ — بازگردانی چنداعتباری با Refund

## هدف

ثابت می‌کند Refund دقیقاً به allocationهای مصرف‌شده‌ی همان Payment برمی‌گردد و Credit unrestricted جدید نمی‌سازد.

## قرارداد Restoration پکیج

پکیج فعلی Refund را به ترتیب **شناسه allocation اصلی** (همان ترتیب مصرف FIFO در Payment) انجام می‌دهد — نه به‌صورت reverse.

مثال: اگر Payment از A سپس B مصرف کرده باشد، Refund اول باقی‌مانده‌ی allocation مربوط به A را پر می‌کند، بعد B.

## وضعیت اولیه

| Credit | مقدار |
|---|---:|
| A | 300,000 |
| B | 500,000 |
| C | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 1,500,000 |

## عملیات ۱ — Payment 600,000

### عملیات

```text
Payment = 600,000
```

Allocation:

```text
A = 300,000
B = 300,000
```

### انتظار

| Credit | قبل | مصرف | بعد |
|---|---:|---:|---:|
| A | 300,000 | 300,000 | 0 |
| B | 500,000 | 300,000 | 200,000 |
| C | 700,000 | 0 | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 900,000 |

| Payment refundable | 600,000 |

## عملیات ۲ — Refund 200,000

### عملیات

```text
Refund = 200,000
```

طبق قرارداد allocation-id order، ابتدا allocation مربوط به Credit A پر می‌شود:

```text
Credit A ← 200,000
```

### انتظار

| Credit | قبل | بازگشت | بعد |
|---|---:|---:|---:|
| A | 0 | 200,000 | 200,000 |
| B | 200,000 | 0 | 200,000 |
| C | 700,000 | 0 | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 1,100,000 |

| Payment refundable | 400,000 |
| تعداد Creditها | 3 (بدون ردیف جدید) |

> اگر قرارداد reverse بود، انتظار می‌شد A=0 و B=400,000؛ اما implementation فعلی این‌گونه نیست.

## عملیات ۳ — Refund 400,000

### عملیات

```text
Refund = 400,000
```

باقی‌مانده‌ی allocation A (=100,000) سپس تمام allocation B (=300,000).

### انتظار

| Credit | قبل | بازگشت | بعد |
|---|---:|---:|---:|
| A | 200,000 | 100,000 | 300,000 |
| B | 200,000 | 300,000 | 500,000 |
| C | 700,000 | 0 | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 1,500,000 |

| Payment refundable | 0 |

## وضعیت نهایی

همه‌ی Creditها به مقدار اولیه‌شان برگشته‌اند. Refund هیچ Credit unrestricted جدیدی نساخته است.

## کنترل حسابداری سناریو

```text
Charge 1,500,000 − Payment 600,000 + Refund 600,000 = 1,500,000
```
