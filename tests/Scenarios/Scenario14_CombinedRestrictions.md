# سناریو ۱۴ — ترکیب محدودیت Club و Service

## هدف

ثابت می‌کند تقاطع (intersection) محدودیت‌های باشگاه و سرویس درست محاسبه می‌شود.

## وضعیت اولیه

| Credit | مقدار | Club | Service |
|---|---:|---|---|
| A | 300,000 | Club A | Swimming |
| B | 400,000 | Club A | بدون محدودیت |
| C | 500,000 | بدون محدودیت | Swimming |
| D | 600,000 | بدون محدودیت | بدون محدودیت |

| Total | 1,800,000 |

شناسه‌ها: Club A=1 ، Club B=2 ، Swimming=10 ، Gym=20

## Eligible Balance قبل از هر Payment

| ترکیب | Creditهای واجد شرایط | Eligible |
|---|---|---:|
| Club A + Swimming | A + B + C + D | 1,800,000 |
| Club A + Gym | B + D | 1,000,000 |
| Club B + Swimming | C + D | 1,100,000 |
| Club B + Gym | D | 600,000 |

## عملیات ۱ — Club A + Swimming = 200,000

Eligible: همه. FIFO از A:

| Credit | مصرف | بعد |
|---|---:|---:|
| A | 200,000 | 100,000 |
| B | 0 | 400,000 |
| C | 0 | 500,000 |
| D | 0 | 600,000 |

## عملیات ۲ — Club A + Gym = 500,000

Eligible: B, D (A و C شنا هستند):

| Credit | مصرف | بعد |
|---|---:|---:|
| A | 0 | 100,000 |
| B | 400,000 | 0 |
| C | 0 | 500,000 |
| D | 100,000 | 500,000 |

## عملیات ۳ — Club B + Swimming = 600,000

Eligible: C, D:

| Credit | مصرف | بعد |
|---|---:|---:|
| A | 0 | 100,000 |
| B | 0 | 0 |
| C | 500,000 | 0 |
| D | 100,000 | 400,000 |

## عملیات ۴ — Club B + Gym = 400,000

Eligible: فقط D:

| Credit | مصرف | بعد |
|---|---:|---:|
| D | 400,000 | 0 |

## وضعیت نهایی

| Credit | remaining | نکته |
|---|---:|---|
| A | 100,000 | فقط برای Club A + Swimming |
| B | 0 | |
| C | 0 | |
| D | 0 | |
| Balance | 100,000 | |

## کنترل حسابداری سناریو

```text
1,800,000 − 200,000 − 500,000 − 600,000 − 400,000 = 100,000
```
