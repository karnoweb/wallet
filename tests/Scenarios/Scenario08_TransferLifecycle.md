# سناریو ۰۸ — چرخه انتقال (Transfer)

## هدف

انتقال ارزش بین دو کیف‌پول بدون ایجاد یا حذف پول، و حفظ lineage روی Credit مقصد.

## وضعیت اولیه

| شخص | Balance |
|---|---:|
| Ali | 1,000,000 |
| Reza | 200,000 |
| **جمع** | **1,200,000** |

## عملیات ۱ — Transfer علی → رضا 400,000

### عملیات

```text
Ali → Reza = 400,000
```

### انتظار

| شخص | قبل | تغییر | بعد |
|---|---:|---:|---:|
| Ali | 1,000,000 | −400,000 | 600,000 |
| Reza | 200,000 | +400,000 | 600,000 |
| جمع | 1,200,000 | 0 | 1,200,000 |

Credit مقصد Reza:

- `parent_credit_id` به Credit منبع Ali اشاره دارد
- `source_wallet_id` = wallet علی
- `remaining = original = 400,000`

مبالغ Transaction بدهکار منبع و بستانکار مقصد برابرند.

## عملیات ۲ — Payment رضا 250,000

### عملیات

```text
Reza Payment = 250,000
```

### انتظار

| شخص | Balance |
|---|---:|
| Ali | 600,000 |
| Reza | 350,000 |
| جمع | 950,000 |

## عملیات ۳ — Payment علی 100,000

### عملیات

```text
Ali Payment = 100,000
```

### انتظار

| شخص | Balance |
|---|---:|
| Ali | 500,000 |
| Reza | 350,000 |
| جمع | 850,000 |

## وضعیت نهایی

| قلم | مقدار |
|---|---:|
| Initial total | 1,200,000 |
| Payments | 250,000 + 100,000 = 350,000 |
| Final total | 850,000 |

## کنترل حسابداری سناریو

```text
1,200,000 − 350,000 = 850,000
```

Transfer خودش پول ایجاد یا حذف نکرده است.
