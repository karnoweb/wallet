# سناریو ۰۲ — پرداخت چنداعتباری با FIFO

## هدف

مصرف چند Credit را بر اساس استراتژی FIFO (`created_at ASC, id ASC`) بررسی می‌کند.

## وضعیت اولیه

سه Charge پشت‌سرهم:

| Credit | مقدار |
|---|---:|
| A | 300,000 |
| B | 500,000 |
| C | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 1,500,000 |

## عملیات ۱ — Payment 600,000

### عملیات

```text
Payment = 600,000
```

FIFO باید ابتدا A سپس B را مصرف کند:

```text
Credit A → 300,000
Credit B → 300,000
```

### انتظار

| Credit | قبل | مصرف | بعد |
|---|---:|---:|---:|
| A | 300,000 | 300,000 | 0 |
| B | 500,000 | 300,000 | 200,000 |
| C | 700,000 | 0 | 700,000 |

| Wallet | Balance |
|---|---:|
| Ali | 900,000 |

## عملیات ۲ — Payment 500,000

### عملیات

```text
Payment = 500,000
```

مصرف:

```text
Credit B → 200,000
Credit C → 300,000
```

### انتظار

| Credit | قبل | مصرف | بعد |
|---|---:|---:|---:|
| A | 0 | 0 | 0 |
| B | 200,000 | 200,000 | 0 |
| C | 700,000 | 300,000 | 400,000 |

| Wallet | Balance |
|---|---:|
| Ali | 400,000 |

## وضعیت نهایی

| قلم | مقدار |
|---|---:|
| Charged | 1,500,000 |
| Paid | 1,100,000 |
| Balance | 400,000 |

## کنترل حسابداری سناریو

```text
1,500,000 − 1,100,000 = 400,000
```
